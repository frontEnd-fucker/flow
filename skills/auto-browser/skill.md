---
name: auto-browser
description: 根据验收标准自动在浏览器中验证
---

**开始时：**
1. 读取 `docs/requirements.md` 文件中的验收标准
2. **必须**使用 `AskUserQuestion` tool 让用户选择，格式如下：

```
AskUserQuestion 参数：
- question: "请选择要验证的验收标准项目"
- options: 
  1. "用户可以通过邮箱和密码登录"
  2. "密码错误时显示提示信息"
  ...
- multiSelect: true
```

⚠️ **重要**：如果不使用 AskUserQuestion 工具，用户无法方便地多选项目。
必须调用工具，禁止直接输出文本列表。

**用户选择后：**
向用户确认："我来在浏览器中验证以下验收标准：" [列出用户选择的项目]

```
示例：
> 我来在浏览器中验证以下验收标准：
> - [ ] 用户可以通过邮箱和密码登录
> - [ ] 登录成功后跳转到首页
```

### 验证步骤

1. 使用 chrome-devtools-mcp 在浏览器中验证用户选择的验收标准
2. 有问题自动分析根本原因，并自动修复
3. 修复完成后在浏览器中重新验证

### 完成后

1. 向用户展示验证总结（仅针对已验证的项目）
2. 使用`code-review/skill.md` review代码
